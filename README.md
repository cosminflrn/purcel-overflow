# 🐷 Purcel Overflow

Tower defense în browser: porci roz invadează biroul unui programator. Apără-l cu capsatoare, imprimante, firewall-uri și rățuște de debug, și ai grijă ce aprobi când Claude cere voie să ruleze comenzi.

**Joacă aici:** https://cosminflrn.github.io/purcel-overflow/

- 6 nivele, fiecare cu hartă, eveniment și muzică proprii (inclusiv lifturi care teleportează porcii)
- 8 capcane care se deblochează pe parcurs, 10 tipuri de porci, inclusiv Porcul Rege
- Se întinde pe tot ecranul, pe orice dispozitiv
- Muzică și sunete generate din cod (Web Audio), fără fișiere externe
- Pe iPhone: Share → Adaugă pe ecranul principal, pentru ecran complet

## Versiuni

Fiecare versiune are o ramură salvată (`versiune-v1.0`, `versiune-v2.0`, ...), iar versiunea curentă apare în colțul din dreapta-jos al meniului. Pentru rollback: GitHub → Branches → alegi versiunea, sau `git checkout versiune-v1.0 -- index.html`, apoi commit și push pe `main`.
